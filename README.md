# **RISC-V 32 bit processor**

A general RV32IM processor with 5 stage pipelined design with L1 cache(4-way set associative with LRU, write-back with write-allocate and read-through policies) using System Verilog for design and Python (cocotb) for testing.

Passes the [ACT4](https://github.com/riscv/riscv-arch-test/tree/act4) for RV32IM instruction set.
